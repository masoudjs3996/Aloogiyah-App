# AlooGiyah Admin

پنل مدیریت الوگیاه؛ راهنمای منطق حمل و هزینه‌ها در `../docs/interhub-delivery.md` است.

```powershell
Copy-Item .env.example .env
npm ci
npm run dev
```

http://127.0.0.1:5174

این پنل به بک‌اند اصلی همین مخزن متصل می‌شود. حساب واردشده باید نقش مدیر یا ادمین داشته باشد. برای انتشار، نشانی سرور و فایل‌ها باید HTTPS باشند.

```powershell
$env:VITE_API_BASE_URL="https://api.aloogiyah.ir/api"
$env:VITE_MEDIA_BASE_URL="https://api.aloogiyah.ir"
npm run build
```

## چیدمان پنل

- کارهای روزمره در بالای منو قرار دارند؛ سایر بخش‌ها دسته‌بندی و جمع می‌شوند. جست‌وجوی منو، نام بخش را پیدا می‌کند.
- در «میدان بار و تحویل»، ابتدا خرید را پیدا کنید و «رسیدگی» را بزنید. راهنمای «قدم پیشنهادی» بر اساس وضعیت بار تغییر می‌کند.
- ورود به میدان بدون کد خریدار است. بار بین‌شهری به ترتیب ورود به مبدأ، اعزام مسیر و ورود به میدان دریافت ثبت می‌شود. پس از آماده‌شدن همه اقلام، نماینده و زمان را مشخص کنید؛ کد شش‌رقمی فقط هنگام تحویل واقعی به خریدار استفاده می‌شود.
- ثبت و ویرایش میدان‌ها و مسیرها در بخش‌های جدا انجام می‌شود. فرم‌ها با دکمه «افزودن» یا «ویرایش» باز می‌شوند.
- فهرست‌های عمومی روی موبایل به کارت تبدیل می‌شوند. جزئیات از «مشاهده» و سایر کارها از منوی «عملیات» در دسترس‌اند. بازپرداخت سفارش کشاورزی فقط برای درخواست بازپرداخت فعال نشان داده می‌شود.
- جست‌وجوی داخل جدول روی همان صفحه است؛ «فیلترها» کل فهرست را محدود می‌کند. در تحویل، جست‌وجوی کد خرید در سرور انجام می‌شود و فیلترهای وضعیت روی صفحه جاری هستند.
- در تسویه، درخواست‌ها، نرخ‌ها و تقویم جدا هستند. مشاهده یا خروجی گرفتن، واریز بانکی انجام نمی‌دهد.
- اطلاعات تکمیلی، سوابق و شناسه‌ها به‌صورت بازشدنی نمایش داده می‌شوند. همه داده‌ها و عملیات قبلی حفظ شده‌اند.

برای نمایش وضعیت دقیق تأیید/ارسال هر قلم در پنل تحویل، نسخه همراه بک‌اند نیز باید منتشر شود؛ تغییر این وضعیت‌های نمایشی مهاجرت جدیدی نیاز ندارد. مهاجرت قبلی رزرو کیف پول، در صورت اجرا نشدن، همچنان لازم است.

## بررسی رابط

پس از ساخت با `VITE_API_BASE_URL` معتبر، روی ویندوز دارای Chrome:

```powershell
node tests/admin-ui.cjs
```

این بررسی از داده‌های آزمایشی مستقل استفاده می‌کند و به سرور واقعی درخواست نمی‌فرستد. صفحات عمومی، مسیر کامل تحویل، نمایش مجاز بازپرداخت، بخش‌های تسویه، همکاری، خرید و تنظیمات در اندازه موبایل و دسکتاپ بررسی می‌شوند. تصاویر در `../.tmp/admin-ui` ذخیره می‌شوند.
